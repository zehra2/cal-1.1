## 5. Technical SEO Findings

### ✅ What's Working
- HTTPS: **Confirmed**
- Canonical tag on homepage: **Confirmed** (`https://americacalculator.com/`)
- Sitemap.xml: **Exists** (referenced in robots.txt)
- Robots.txt: **Exists and properly structured**
- OG tags: **Present** (title, description, URL, image, type, site_name)
- WebSite + Organization + FAQPage schema on homepage: **Present**

### ❌ Technical Issues Found

**CRITICAL:**

1. **Dead navigation links** — `Math` and `Technology` both point to `/#` (anchor to nothing)
   - This means crawlers and users clicking these categories get nowhere
   - Fix: Create `/math/` and `/technology/` category pages and link to them
   - Impact: Crawlability + internal link equity + user experience

2. **Old .php calculator pages still indexed** — GSC shows `/calculators/overtime.php`, `/calculators/investment-growth-calculator`, `/calculators/rvu.php` getting impressions
   - These should be 301-redirected to their modern equivalents or noindexed if duplicates
   - Impact: Crawl budget waste + duplicate content risk

3. **Robots.txt disallows specific .php pages** but does NOT 301-redirect them
   - Disallowing in robots.txt is not the same as removing from index — you need proper redirects or noindex tags
   - Fix: Audit all disallowed .php pages; 301 redirect to correct canonical pages

**HIGH:**

4. **Schema is only on homepage** — no per-page schema for individual calculator tools
   - The closing cost calculator, SBA loan calculator, home addition calculator each need `WebApplication` or `SoftwareApplication` schema + `FAQPage` schema
   - Impact: Rich result eligibility, AEO/GEO visibility

5. **No `lastmod` dates in sitemap** — Google cannot determine content freshness
   - Fix: Add `<lastmod>` dates to every URL in sitemap.xml

6. **Image alt text not verified** — OG image uses a space in filename: `logo-america%20calculator.jpg`
   - Rename image files without spaces; verify all calculator tool images have descriptive alt text

**MEDIUM:**

7. **No breadcrumb schema** on inner pages (confirmed BreadcrumbList missing from schema scan)
8. **No Twitter/X Card meta tags** — add `twitter:card`, `twitter:title`, `twitter:description`
9. **No `hreflang`** — all content is English/US but not declared explicitly

## 12. Conversion / AdSense SEO Gap

**Goal: 50 clicks/day → ~1,825 clicks/month → $500 AdSense revenue**

This requires a **3%+ AdSense RPM** (revenue per 1,000 impressions) which is realistic for finance/calculator niches ($5–$20 RPM is common for US finance content).

**Model:**
```
To earn $500/month at $10 RPM (conservative US finance):
Need: 50,000 page views/month = ~1,667/day
At 50 clicks/day from SEO and good bounce rate / pages-per-session:
If 1 click = 1.5 page views average → 75 page views/day from SEO alone = $0.75/day → $22.50/month
NOT enough alone.

Correct model:
Target: 300–500 organic clicks/day (not 50)
At 300 clicks/day × 1.5 pages/session = 450 sessions/day
× $8 RPM = $3.60/day → $108/month

At 500 clicks/day:
500 × 1.5 = 750 sessions × $8 RPM = $6/day → $180/month

To hit $500/month at $8 RPM, you need ~2,000 page views/day = ~1,300+ organic clicks/day
```

> **Honest assessment:** 50 clicks/day will NOT generate $500/month from AdSense unless your RPM is extremely high (unlikely for a new site). The realistic path is:
> - **30-day goal:** 50 clicks/day ✅ (achievable with fastest wins)
> - **90-day goal:** 300+ clicks/day
> - **6-month goal:** 1,000+ clicks/day → then $500/month AdSense becomes realistic

**AdSense placement strategy for calculator sites:**
1. Place a leaderboard (728×90) above the calculator
2. Place a rectangle (300×250) between the calculator result and the explanation content
3. Place a responsive ad at the bottom of the FAQ section
4. Never place ads inside the calculator itself — it disrupts UX and destroys engagement

# Output Format — Every Calculator Task

When asked to build or revamp a calculator page, always deliver in this
exact order:

1. **Page Title + Meta Description**
   - Full `<title>` following the title formula
   - Full meta description (150–160 chars)

2. **URL Suggestion**
   - Final slug following `/{cluster}/{calculator-name}`

3. **Full HTML/JSX Structure**
   - Calculator UI (inputs, outputs, validation)
   - Full supporting content (how-to, formula, examples, pros/cons, FAQ,
     related calculators) per `content-structure.md` / `seo-rules.md`

4. **SEO Elements**
   - H1 / H2 / H3 outline
   - WebApplication + FAQPage + HowTo JSON-LD (complete, matching on-page
     content exactly)
   - List of internal links added (cluster + guide)

5. **Next Steps**
   - Interlinking recommendations (which existing pages to update with a
     link to this new one)
   - Google Search Console checks to run once live (target queries to
     watch, expected CTR issues to monitor)

## Confirmation gate
Before generating the full page (step 3 onward), always summarize the plan
(title, URL, section outline) in 3–5 lines and wait for explicit
confirmation to proceed — unless the user has already said "build it" or
equivalent for this specific calculator.
